# Time Complexity (Introduction)

Time Complexity tells us **how fast an algorithm runs** as input size grows.

## Common Time Complexities
- O(1) → Constant time
- O(n) → Linear time
- O(n²) → Quadratic time
- O(log n) → Logarithmic time

## Example

```python
# O(n) time complexity
for i in range(n):
    print(i)
