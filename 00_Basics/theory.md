# What is DSA?

DSA stands for **Data Structures and Algorithms**.

- **Data Structure** → Way to store and organize data
- **Algorithm** → Step-by-step procedure to solve a problem

## Examples
- List, Stack, Queue → Data Structures
- Searching, Sorting → Algorithms

---

# Why DSA is Important?

1. Improves problem-solving skills
2. Required for coding interviews
3. Helps write optimized code
4. Used in real-world systems (search engines, maps, AI)

---

# Why Python for DSA?

- Simple syntax
- Faster implementation
- Large standard library
- Widely used in interviews

---

# Problem-Solving Approach

1. Understand the problem
2. Identify inputs & outputs
3. Think of brute-force solution
4. Optimize using DSA
5. Analyze time & space complexity
